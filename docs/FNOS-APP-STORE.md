# 飞牛应用中心发布说明

SongLib Amp 提供符合飞牛 fnOS 应用包结构的 Docker 应用，源码位于 `packaging/fnos/songlib-amp`。

## 应用信息

- 应用名称：SongLib Amp
- 应用包名：`songlib-amp`
- 当前版本：`1.2.3`
- 支持架构：x86_64、arm64
- 服务类型：本地优先的 NAS 音乐管理与播放平台
- 项目主页：<https://github.com/songdone/songlib-amp>
- 容器镜像：<https://hub.docker.com/r/666uos/songlib-amp/tags>

## 应用中心安装体验

安装时只需选择存储位置并确认访问端口。系统会创建互相独立的 `songlib-amp/music` 与 `songlib-amp/downloads` 共享目录，并使用飞牛应用私有数据目录保存账号、配置、任务、数据库和备份。

安装完成后，从飞牛桌面打开应用：

1. 创建主人账号。
2. 连接 Plex 或直接扫描 `music` 共享目录。
3. 在设置页按需连接飞牛音乐与授权音乐源。
4. 在下载与入库页把 `downloads` 中的文件预览、规范命名并移动到正式音乐库。

应用不会内置第三方私钥、绕过 DRM 或附带受版权保护的音频。

## 发布前验证

发布材料应包含最终 `.fpk`、64/256 px 应用图标、真实界面截图和测试记录。测试至少覆盖：

- 安装、首次打开、创建主人账号与再次登录。
- Docker 镜像拉取、容器健康检查、应用中心启动/停止状态。
- 私有数据、音乐库与下载目录在容器重启后的持久化。
- Plex 连接、媒体库、搜索、歌手/专辑详情、播放队列与歌词。
- 歌单同步、下载入库、任务中心和设置。
- x86_64 实机安装以及 amd64/arm64 镜像清单核验。
