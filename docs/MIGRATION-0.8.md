# 从 0.8 升级

1. 停止旧实例前先使用 SQLite Backup API 或 NAS 快照备份数据目录。
2. 新建独立应用目录并复制数据库备份；不要让新旧实例共享数据卷。
3. 使用新的 `.env.example` 创建配置，移除硬编码 NAS 地址、资料库编号和媒体前缀。
4. 启动新实例。版本化迁移会保留用户、来源、任务、本地文件和 Plex 条目，并新增歌单、画像、审计、适配器和隔离数据表。
5. 旧的 `queued` 任务仍可领取；过期的 `running` 任务回到队列，不再直接标记失败。
6. 在设置页重新测试 Plex，确认容器桥接网络下的地址和路径映射。
7. 依次验证扫描、播放、歌词、歌单导入和备份后，再停用旧实例。

旧来源会以禁用或待验证状态保留，需要重新执行格式检查、搜索测试和解析测试后才能用于下载。

数据库迁移是只向前的。回滚应用版本时应恢复升级前备份，而不是直接用旧程序打开已迁移数据库。
